# Phase 6C Agent Personality UI Plan

## 0. 目的

Phase 6Cでは、各エージェントの違いを「説明文を読まなくても感じられる」UIへ近づけます。

人格定義や会話生成ロジックは変更しません。既存の `AGENTS` 定義を尊重し、表示・光・動き・状態文言・モーダルの見え方だけを強化します。

## 1. 基本方針

- 色だけで差別化しない
- エージェントごとの質感を出す
- 派手にしすぎない
- 読みやすさを優先する
- 既存ロジックは触らない
- 後段CSS/JSとして追加し、戻しやすくする

## 2. 各エージェントのUI人格

### レイ

- 静かな鏡
- 青紫、透明感、水面の反射
- 選択時は大きく跳ねず、静かに明るくなる

### ジョー

- 火花、灯台、前進感
- 金色、少し強い光
- 選択時は上方向に小さく浮く

### ミナ

- 包む、泉、安心
- ローズ、丸さ、呼吸感
- 選択時はやさしく膨らむ

### サトウ

- 守る、地面、重心
- 赤/土色、輪郭の強さ
- 選択時は安定して重く見える

### ケン

- 整える、構造、設計図
- 青/シアン、線、整列
- 選択時は線が通るように見える

### フィオ

- 連れ出す、風、軽さ
- 緑/ミント、斜め方向、抜け感
- 選択時は軽く斜めに浮く

### トム

- 壊す、突破、ノイズ
- 紫/マゼンタ、少しエッジ
- 選択時は微細なノイズ感を出す

### 委ねる

- 場そのもの
- 7色の合流、円環、無限記号
- 選択時は複数色がゆっくり巡る

## 3. 実装方針

追加するファイル:

- `css/phase6c-agent-personality.css`
- `js/phase6c-agent-personality.js`

更新するファイル:

- `index.html`
- `README.md`

## 4. JS側の役割

`phase6c-agent-personality.js` は、既存の `UI.renderAgentIcons`、`UI.addAgentMessage`、`UI.showPersonaModal` を後段から軽く拡張します。

行うこと:

- agent-cardに `agent-card--ray` などのclassを付与
- agent-cardに `data-agent-id` を付与
- bodyに現在選択中の `data-current-agent` を付与
- AgentStatusの文言を各エージェントらしくする
- エージェント返信に `message-agent--ray` などのclassを付与
- PersonaModalに質感ラベルを追加

## 5. CSS側の役割

`phase6c-agent-personality.css` は、各エージェントの見え方を調整します。

行うこと:

- agent-cardの個性付け
- selected時の光り方の差分
- AgentStatusの質感差分
- ChatBubbleのアクセント差分
- PersonaModalの質感ラベル
- `委ねる` の多色表現

## 6. やらないこと

- `js/agents.js` の人格定義変更
- `js/chat.js` の会話生成変更
- `js/modes.js` のモード判定変更
- 保存データ構造変更
- 外部API接続
- 認証/DB追加
- 大規模HTML構造変更

## 7. 完了条件

- 各エージェントのカードに個性が出る
- 選択中の声がより直感的に分かる
- 現在の声ステータスがその声らしい文言になる
- エージェント返信の左ラインやバブルに声の質感が出る
- プロフィールモーダルに、その声の質感が短く表示される
- 既存の会話や保存は壊れない
