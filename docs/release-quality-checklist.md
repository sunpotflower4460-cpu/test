# 公開前品質チェックリスト

この文書は、じぶん会議 test版を Cloudflare Pages で公開する前に確認するためのチェックリストです。

Phase 5では、アプリの中身を大きく変えず、公開前に見るべきポイントを整理します。

## 1. 基本表示チェック

- [ ] スプラッシュ画面が表示される
- [ ] 「はじめる」を押してメイン画面に入れる
- [ ] 初回オンボーディングが表示される
- [ ] オンボーディングを最後まで進められる
- [ ] スキップボタンが動く
- [ ] 画面全体が横にはみ出さない
- [ ] ダークモードで違和感がない
- [ ] ライトモードで違和感がない

## 2. チャット体験チェック

- [ ] 入力欄に文字を入力できる
- [ ] 送信ボタンが押せる
- [ ] ユーザー発言が表示される
- [ ] エージェント返信が表示される
- [ ] 返信下に「他の声も聞く」が表示される
- [ ] 返信下に「会議録に残りました」が表示される
- [ ] 長文を入力しても表示が大きく崩れない
- [ ] 入力後、画面下部が入力欄に隠れすぎない

## 3. エージェント体験チェック

- [ ] エージェントバーが表示される
- [ ] 横スクロールできる
- [ ] 各エージェントを選択できる
- [ ] 選択中エージェントが分かりやすい
- [ ] `委ねる` カードが表示される
- [ ] `委ねる` を選んだ時の表示が自然
- [ ] 入力欄上の現在の声ステータスが表示される
- [ ] エージェント長押しでプロフィールが開く
- [ ] プロフィールモーダルを閉じられる

## 4. 会議録チェック

- [ ] メニューを開ける
- [ ] サイドバータイトルが `会議録` になっている
- [ ] 新しい会議を作れる
- [ ] 会議録にタイトルが表示される
- [ ] 会議録に日付が表示される
- [ ] 会議録にメッセージ数が表示される
- [ ] 会議録を切り替えられる
- [ ] 会議録を削除できる
- [ ] 最後の1件を削除しようとしても壊れない

## 5. 関係性マップチェック

- [ ] ヘッダーのマップボタンを押せる
- [ ] 星座風の関係性マップが表示される
- [ ] 中央に `あなた` が表示される
- [ ] 周囲に7人の声が表示される
- [ ] 凡例が読める
- [ ] モーダル内をスクロールできる
- [ ] モーダルを閉じられる
- [ ] 小さい画面でも大きく崩れない

## 6. スマホ実機チェック

最低限、iPhone Safari またはスマホChromeで確認します。

- [ ] 画面下部の入力欄がホームバーに隠れない
- [ ] キーボード表示時に入力欄が極端に崩れない
- [ ] 文字入力時に勝手にズームしない
- [ ] エージェントバーが押しやすい
- [ ] 横スクロールが重すぎない
- [ ] サイドバーが画面幅に収まる
- [ ] モーダルが画面外にはみ出しすぎない
- [ ] 関係性マップが読める
- [ ] トーストが左右にはみ出さない

## 7. データ保持チェック

このtest版は、現時点ではブラウザのlocalStorageを使います。

- [ ] ページを再読み込みしても会議録が残る
- [ ] 新しい会議を作っても既存会議が残る
- [ ] 削除した会議が再読み込み後も消えている
- [ ] ブラウザの別端末では同期されないことを理解している

## 8. Cloudflare公開前チェック

Cloudflare Pagesで公開する前に確認します。

- [ ] `index.html` がルートにある
- [ ] `css/` が含まれている
- [ ] `js/` が含まれている
- [ ] `manifest.json` が含まれている
- [ ] Build command は空欄または不要
- [ ] Build output directory は `/` またはルート相当
- [ ] 環境変数は現時点では不要
- [ ] 公開URLを開いて表示確認した

## 9. 公開後チェック

公開URLで確認します。

- [ ] トップ画面が開く
- [ ] スプラッシュからメインへ入れる
- [ ] 入力と返信が動く
- [ ] 会議録が動く
- [ ] 関係性マップが開く
- [ ] スマホで開いて大きく崩れない
- [ ] READMEの説明と実際の挙動が大きく矛盾しない

## 10. 既知の注意点

- この版は本流じぶん会議とは別の軽量UI実験版
- 現時点では外部AI APIには接続していない
- 現時点では認証やクラウド同期はない
- 会議録はブラウザ内保存
- VercelではなくCloudflare Pages手動デプロイ前提
- 本番公開や独自ドメイン接続は手動ゲート

## 11. 次に改善すると良いこと

公開前後に余裕があれば、次を検討します。

- 実機スクリーンショットを見ながらUI微調整
- READMEに現在の画面説明を追加
- Cloudflare公開URLをREADMEに追記
- PWAアイコンやmanifestの見直し
- 初回ガイド文言のさらに自然化
- 会議録のタイトル編集
- エージェントプロフィールの読みやすさ改善
