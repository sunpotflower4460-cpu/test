# Phase 6D UI Animation Plan

## 0. 目的

Phase 6Dでは、じぶん会議 test版のUI反応を上質にします。

対象は、エージェント選択、返信表示、入力欄、モーダル、トースト、サイドバーです。

## 1. 基本方針

- 動きは控えめにする
- 読みやすさを優先する
- スマホで重くしない
- reduced-motion を尊重する
- 既存ロジックは変更しない
- 追加CSS/JSで後段から効かせる

## 2. 対象

- エージェント選択時の反応
- 委ねるカードのゆっくりした光
- 返信表示時の自然な出現
- 入力欄フォーカス時の見え方
- モーダルの出入り
- トーストの出入り
- サイドバーの開閉感

## 3. 実装ファイル

追加するファイル:

- `css/phase6d-ui-animation.css`
- `js/phase6d-ui-animation.js`

更新するファイル:

- `index.html`
- `README.md`

## 4. CSS側でやること

- selected agent card の反応を整える
- delegate card の多色表現を少し滑らかにする
- new message 表示時の class を用意する
- input focus の見た目を整える
- modal/sidebar/toast の出入りを整える
- reduced-motion 時は大きな動きを止める

## 5. JS側でやること

- 新しく表示された返信に短時間だけ class を付ける
- 送信ボタンに短時間だけ class を付ける
- 既存UI関数を後段から軽く拡張する

## 6. やらないこと

- 会話生成ロジック変更
- エージェント定義変更
- 保存データ構造変更
- API接続
- 認証/DB追加
- 大規模HTML変更

## 7. 完了条件

- 返信表示が自然に見える
- エージェント選択が分かりやすい
- 入力欄の状態が分かりやすい
- モーダルとトーストが雑に見えない
- reduced-motion が守られている
- 既存機能が壊れていない
